# How to use this file

## Install

Put this `nudge` folder in your agent's skills folder, in the right place for your project:

- Claude Code: `.claude/skills/`
- Cursor: `.cursor/skills/`
- Codex: `.codex/skills/`

Not sure where that is? Ask your agent to do it for you.

## Use

Show your agent a screenshot, a page, a Figma frame or code, and ask for a design review. In Claude Code you can also type `/nudge`.

Get the latest version at [shiftnudge.com/skill](https://shiftnudge.com/skill?utm_source=skill&utm_medium=readme&utm_campaign=shift-nudge-skill&utm_content=install).
